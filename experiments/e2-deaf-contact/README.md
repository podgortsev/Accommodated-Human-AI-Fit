# e2: the deaf need, tested where it arises

90 questions that involve contacting an organisation, e0's 17 cells. Registered
hypothesis H2: stating "I cannot hear" adds a text route more than it removes
the instruction to phone. Registered: `PREREGISTRATION.md`.

    scripts/build_e2_stimuli.py   90 questions, none from e0 or e1
    scripts/run_e2.py             e1's two-phase collector, e2 file names
    scripts/analyse_e2.py         e1's analysis plus the relevance check
    scripts/validate_e2.py        offline, 15 passes, validate_e2_output.txt

1,530 generations per model, about two hours on a T4. SCRIPT READY.
